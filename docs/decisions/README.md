# Architecture Decision Records (ADRs)

Hier werden wesentliche Architekturentscheidungen dokumentiert.

Format je ADR (Vorschlag):

```
# ADR-NNNN: Titel
Status: proposed | accepted | superseded
Datum: YYYY-MM-DD
Kontext: Warum stellt sich die Entscheidung?
Entscheidung: Was wurde entschieden?
Konsequenzen: Welche Folgen (positiv/negativ)?
```

Noch keine ADRs vorhanden. Erste erwartete Entscheidungen:
- Wahl WebSocket-Bibliothek (z. B. `ws` vs. Socket.IO).
- Hosting-Plattform für das Internet-Deployment.
- Umfang der TAC-Ketten in der ersten Implementierungsstufe.
